# DSCI-270-project
This project focused on developing data manipulation workflows, explanatory visualizations, and predictive models using Python. Multiple datasets were leveraged to practically apply structural methodologies learned in course modules, focusing extensively on data restructuring, visualization, and analysis using pandas and NumPy. During the exploratory data analysis (EDA) phase, several distinct datasets were evaluated to extract meaningful structural insights. For the student performance dataset, standardized test scores were analyzed based on preparation status, which included data engineering to generate a new total score column by summing separate sectional scores and dividing them to establish a final composite metric. Segmenting this data by gender revealed that male students achieved higher average math scores, while female students achieved higher average scores in both reading and writing; furthermore, structured bar plots and histograms verified that students who engaged in prior study consistently achieved higher score distributions than those who did not. Analysis of the Netflix dataset focused on catalog depth across release years and content formats, determining that the earliest archived cinematic release date within the dataset was 1942 and establishing that the volume of available movies substantially outnumbers television shows. For the Airbnb dataset, evaluating regional distribution density across location variables identified a significantly higher concentration of listings clustered specifically within the cities of Brooklyn and Manhattan compared to alternative municipal regions. Finally, predictive modeling was executed on the Spotify dataset to conduct correlation testing between two numeric variables, danceability and popularity. By applying coursework techniques to develop a simple linear regression model, a corresponding trendline was mapped onto the graph, yielding a positive, low-magnitude slope that suggests a slightly significant correlation between a track's danceability and its final popularity score. Throughout these operations, technical challenges were encountered, particularly regarding string extraction and replacement functions when attempting to parse internal dataset text values into modified display formats. These blockages were resolved efficiently by utilizing core educational resources and course textbooks. Additionally, while certain advanced data manipulation ideas could not be fully carried out due to a current lack of coding knowledge, these functional boundaries are being systematically addressed by leveraging readily available data sources and references to supplement specialized programming capabilities.
